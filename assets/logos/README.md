# VaultSieve Logos

Place logo assets for VaultSieve here.

Recommended files:

- `vaultsieve-icon.svg`: square app icon.
- `vaultsieve-wordmark.svg`: horizontal logo with wordmark.
- `vaultsieve-icon.png`: exported square PNG.
- `vaultsieve-wordmark.png`: exported horizontal PNG.

Prefer SVG for source artwork and PNG for previews or platforms that do not support SVG.
